DevLog Frontend

Modern full-stack developer blogging platform built with Next.js, TypeScript, Tailwind CSS, and JWT authentication.

Features
User Authentication (JWT)
Create, Edit & Delete Posts
Responsive Modern UI
Protected Routes
API Integration with Spring Boot Backend
MongoDB Atlas Database
Persistent Login State
Clean Component-Based Architecture

Tech Stack
Frontend:
Next.js
React
TypeScript
Tailwind CSS
Axios

Backend:
Spring Boot
Java
MongoDB Atlas
JWT Authentication
Spring Security
